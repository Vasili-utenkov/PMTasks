Инструкция:  

### Шаг 1. Выбор проекта. 
Для выполнения задания необходимо выбрать один из предложенных кейсов:


### Шаг 2. Сбор данных. 
Выполните сбор данных и составьте характеристику по выбранному ИТ-проекту (тип, размер команды, уровень неопределённости, требования заказчика).

### Шаг 3. Выбор методологии. 
На основе характеристик выбранного проекта обоснуйте выбор методологии управления (Waterfall, Scrum, Kanban или гибридный подход). Заполните таблицу сравнения методологий по критериям из занятия 1.2.  

### Шаг 4. Инициация проекта. 
Составьте устав проекта по шаблону, включающий: - Название и описание проекта. - Цели проекта (минимум 2, сформулированные по SMART). - Реестр стейкхолдеров (минимум 4 роли). - Ограничения и допущения. - Критерии успеха.  

### Шаг 5. Формирование бэклога. 
Напишите 8–10 User Stories в формате «Как _роль_, я хочу _действие_, чтобы _ценность_» с Acceptance Criteria для каждой. Приоритизируйте по MoSCoW.  

### Шаг 6. Оформите результат 
в виде файла формата docx или pdf и загрузите в LMS Odin.
